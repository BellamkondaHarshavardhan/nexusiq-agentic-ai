# IT and Information Security Policy

## Passwords and Authentication
- Passwords must have **at least 14 characters** and must be changed every **90 days**.
- **Multi-factor authentication (MFA)** is mandatory for email, VPN, the code repository and all cloud consoles.
- Never share passwords. Use the company-approved password manager.

## Devices and Network
- All laptops use full-disk encryption and automatic screen lock after 5 minutes.
- Connect to the **company VPN** before accessing internal systems from outside the office.
- Personal USB drives are blocked. Use the approved file-sharing tools instead.

## Data Classification
Information is labelled **Public, Internal, Confidential or Restricted**. Confidential and Restricted data (customer contracts, salary data, source code) must never be pasted into public AI tools or sent to personal email.

## Reporting Incidents
- Report a **lost or stolen device within 2 hours** to the security team at security@nexustech.example or on the incident hotline, extension **4444**.
- Report suspicious emails with the **"Report Phishing"** button in the mail client.
- Security incidents are triaged within 1 hour on business days.

## Using AI Tools
Only company-approved AI services may be used for work. Do not upload customer data, credentials or unreleased source code to unapproved AI tools.
